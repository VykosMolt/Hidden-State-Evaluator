# Utilities

Project-side tools and test suites live here so the repository root stays
small.

- `evaluator/`: evaluator/domain-transfer probes and post-RLTT diagnostic
  bundles.
- `tools/`: shared conversion tools.
- `tests/`: Hunter-Seeker/core unit, integration, report, and local-agent
  wrapper suites.

`pytest.ini` collects `utilities/tests/`.
