# Utility Tools

Shared project tools.

- `convert_rltt_fsdp_to_hf.py`: convert downloaded Ouro/RLTT FSDP shards into
  the local Hugging Face model layout under `shared/models/ouro_rltt_local/`.

Evaluator probes and diagnostic bundles live under `../evaluator/`. Local-agent
tools live under `../../src/local_agent/tools/`.
